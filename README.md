# Probably Stolen 私人备份

[下载游戏和存档备份](https://github.com/slowice/probably-stolen-backup/releases/tag/backup-20261104)

完整游戏和模组位于压缩包的 `Game` 目录，所有 `.es3` 存档位于 `Saves` 目录。恢复步骤见压缩包内的“恢复说明.txt”。

恢复存档前退出游戏并备份现有存档，然后将 `Saves` 中的文件复制到 `%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\`。

压缩包与 SHA-256 校验文件存放在私有仓库的 Releases 中。
